# Life Command Centre Docs

This folder documents the checked-in `life-cc` + `pod` system from two angles:

- `life-cc-architecture.md`: codebase architecture, ownership boundaries, runtime flow, and current backend topology.
- `life-cc-frontend-request-map.md`: every frontend-triggered API/request path that exists in the current code.

These docs describe the code in this checkout today, not a future design.

They may intentionally differ from the currently running Lemma pod until the bundle is imported and published. When there is a mismatch, treat the docs as source-of-truth for the repo and the Lemma CLI as source-of-truth for the live deployment state.
